# Trader Behavior vs Bitcoin Market Sentiment

## Objective
Analyze the relationship between Bitcoin Fear & Greed sentiment and trader performance using Hyperliquid historical trading data.

## Datasets
- Hyperliquid Historical Trader Data
- Bitcoin Fear & Greed Index

## Methodology
1. Data Cleaning
2. Feature Engineering
3. Dataset Merge
4. Exploratory Data Analysis
5. Sentiment-Based Performance Analysis
6. Recommendations

## Key Findings
- Traders achieved higher average PnL during Greed periods.
- Fear periods generated the highest trading volume.
- Win rates increased with positive sentiment.
- Position sizing varied across sentiment regimes.
